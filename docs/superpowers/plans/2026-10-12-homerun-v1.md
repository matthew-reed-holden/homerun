# homerun v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `homerun`, a daemon plus TUI that runs a GitHub repo's push/pull_request workflows under act on the local machine and reports every job back to GitHub as a check run.

**Architecture:** One Go binary. The daemon polls GitHub through a GitHub App, mirrors each repo with `git clone --mirror`, snapshots the exact commit into a detached worktree, filters workflows itself (act ignores `branches`/`paths`), runs one act process per matched workflow with `--json`, and turns act's log events into check-run updates. A unix-socket HTTP API serves the TUI and CLI verbs.

**Tech Stack:** Go 1.27, `github.com/google/go-github/v92`, `github.com/bradleyfalzon/ghinstallation/v2` v2.19.0, `gopkg.in/yaml.v3`, Bubble Tea v1.3 / lipgloss v1.1, act 0.2.89, git, Docker.

**Spec:** `docs/superpowers/specs/2026-10-12-homerun-design.md` (read it first, especially "Findings from the act spike").

## Global Constraints

- Module path: `github.com/matthew-reed-holden/homerun`. Binary: `homerun`. License: MIT.
- Check names: `homerun / <workflow name> / <job name>`; extra checks: `homerun / checks / <name>`; setup failures: `homerun`.
- Check-run `external_id` is the event key: `push:refs/heads/<branch>` or `pull_request:<N>`.
- Default act platform image: `catthehacker/ubuntu:act-latest` for `ubuntu-latest`, `ubuntu-24.04`, `ubuntu-22.04`.
- Host-job label: `homerun-host`, passed to act as `-P homerun-host=-self-hosted`.
- Defaults: `max_parallel: 1`, `poll_interval: 30s`, `retain: 14d`.
- Secret values are never written to disk by homerun, never put in argv, never logged, and are masked in every stored log and every check-run output.
- Pull requests from forks get no secrets; their `host_jobs` and `checks:` report `neutral` with summary `skipped: fork PR`.
- Failures caused by homerun itself (not the user's code) have summaries starting `homerun error:`.
- Check-run output text is capped at 65,535 characters.
- Code comments carry "why" only. No new dependencies beyond the Tech Stack line. Standard `flag` package for the CLI, `log/slog` for logs.
- Files: user config `~/.config/homerun/config.yml` (mode 600); state `$XDG_STATE_HOME/homerun` (default `~/.local/state/homerun`); socket `$XDG_RUNTIME_DIR/homerun.sock`.

## Review Focus

1. **A secret interpolated into a `run:` line** (`echo ${{ secrets.X }}`): act prints it unmasked in its JSON `step` field. The run log, the TUI and the check-run summary must show `***`, including for each line of a multi-line secret such as a PEM. Pinned in Task 2 and Task 6.
2. **A commit that adds `.actrc`, `.secrets`, `.env` or `.vars`:** this must not change act's flags or values. For example, `.actrc` containing `-P ubuntu-latest=-self-hosted` would otherwise move a fork's jobs onto the host. Pinned in Task 8.
3. **A PR whose head repo was deleted** (`head.repo` is null): it must be treated as a fork, so no secrets and no host execution. Pinned in Task 5.
4. **Two pushes to the same PR in quick succession:** the older run is cancelled (queued or running), its check runs end as `cancelled`, and its worktree is removed. Cancellation must not stop the "cancelled" report from reaching GitHub. Pinned in Task 10 and Task 13.
5. **The daemon killed mid-run, then restarted:** no commit runs twice, the stranded check runs are closed as `cancelled` ("runner restarted"), and the run is re-queued. Pinned in Task 14.

```go
package config

import (
	"context"
	"fmt"
	"os"
	"os/exec"
	"strings"

	"gopkg.in/yaml.v3"
)

// Secret is a value from one of three sources. Plain strings are allowed:
// homerun warns about them but leaves secret handling to the user.
type Secret struct {
	Cmd   string
	Env   string
	Value string
}

func (s *Secret) UnmarshalYAML(n *yaml.Node) error {
	switch n.Kind {
	case yaml.ScalarNode:
		s.Value = n.Value
		return nil
	case yaml.MappingNode:
		var m struct {
			Cmd string `yaml:"cmd"`
			Env string `yaml:"env"`
		}
		if err := n.Decode(&m); err != nil {
			return err
		}
		if (m.Cmd == "") == (m.Env == "") {
			return fmt.Errorf("line %d: secret needs exactly one of cmd or env", n.Line)
		}
		s.Cmd, s.Env = m.Cmd, m.Env
		return nil
	}
	return fmt.Errorf("line %d: secret must be a string, {cmd: ...} or {env: ...}", n.Line)
}

func (s Secret) Plaintext() bool { return s.Cmd == "" && s.Env == "" }

func (s Secret) Resolve(ctx context.Context) (string, error) {
	switch {
	case s.Cmd != "":
		out, err := exec.CommandContext(ctx, "sh", "-c", s.Cmd).Output()
		if err != nil {
			// The error carries only the exit status; stdout may hold part of the secret.
			return "", fmt.Errorf("command failed: %w", err)
		}
		return strings.TrimRight(string(out), "\r\n"), nil
	case s.Env != "":
		v, ok := os.LookupEnv(s.Env)
		if !ok {
			return "", fmt.Errorf("environment variable %s is not set", s.Env)
		}
		return v, nil
	}
	return s.Value, nil
}
```

```go
package config

import (
	"fmt"
	"os"
	"path/filepath"
	"regexp"
	"sort"
	"strconv"
	"strings"
	"time"

	"gopkg.in/yaml.v3"
)

const DefaultImage = "catthehacker/ubuntu:act-latest"

// Duration accepts Go durations plus a "d" suffix for days.
type Duration time.Duration

func (d *Duration) UnmarshalYAML(n *yaml.Node) error {
	s := n.Value
	if days, ok := strings.CutSuffix(s, "d"); ok {
		v, err := strconv.Atoi(days)
		if err != nil {
			return fmt.Errorf("line %d: invalid duration %q", n.Line, s)
		}
		*d = Duration(time.Duration(v) * 24 * time.Hour)
		return nil
	}
	v, err := time.ParseDuration(s)
	if err != nil {
		return fmt.Errorf("line %d: invalid duration %q", n.Line, s)
	}
	*d = Duration(v)
	return nil
}

type App struct {
	ID         int64  `yaml:"id"`
	PrivateKey Secret `yaml:"private_key"`
}

type UserRepo struct {
	Secrets map[string]Secret `yaml:"secrets"`
}

type User struct {
	App          App                 `yaml:"app"`
	MaxParallel  int                 `yaml:"max_parallel"`
	PollInterval Duration            `yaml:"poll_interval"`
	Retain       Duration            `yaml:"retain"`
	Platforms    map[string]string   `yaml:"platforms"`
	Repos        map[string]UserRepo `yaml:"repos"`
}

var repoName = regexp.MustCompile(`^[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+$`)

func ValidRepo(name string) bool { return repoName.MatchString(name) }

func DefaultUserPath() string {
	dir, err := os.UserConfigDir()
	if err != nil {
		dir = filepath.Join(os.Getenv("HOME"), ".config")
	}
	return filepath.Join(dir, "homerun", "config.yml")
}

// LoadUser returns the config and human-readable warnings about how it stores secrets.
func LoadUser(path string) (*User, []string, error) {
	b, err := os.ReadFile(path)
	if err != nil {
		return nil, nil, err
	}
	u := &User{}
	if err := yaml.Unmarshal(b, u); err != nil {
		return nil, nil, fmt.Errorf("%s: %w", path, err)
	}
	if u.MaxParallel <= 0 {
		u.MaxParallel = 1
	}
	if u.PollInterval <= 0 {
		u.PollInterval = Duration(30 * time.Second)
	}
	if u.Retain <= 0 {
		u.Retain = Duration(14 * 24 * time.Hour)
	}
	platforms := map[string]string{"ubuntu-latest": DefaultImage, "ubuntu-24.04": DefaultImage, "ubuntu-22.04": DefaultImage}
	for k, v := range u.Platforms {
		platforms[k] = v
	}
	u.Platforms = platforms

	var warns []string
	if fi, err := os.Stat(path); err == nil && fi.Mode().Perm()&0o077 != 0 {
		warns = append(warns, fmt.Sprintf("%s is readable by other users (mode %o); run: chmod 600 %s", path, fi.Mode().Perm(), path))
	}
	if u.App.PrivateKey.Plaintext() && u.App.PrivateKey.Value != "" {
		warns = append(warns, "app.private_key is stored as plaintext; prefer {cmd: ...} or {env: ...}")
	}
	names := make([]string, 0, len(u.Repos))
	for name := range u.Repos {
		if !ValidRepo(name) {
			return nil, nil, fmt.Errorf("%s: repo %q must be owner/name", path, name)
		}
		names = append(names, name)
	}
	sort.Strings(names)
	for _, name := range names {
		keys := make([]string, 0, len(u.Repos[name].Secrets))
		for k := range u.Repos[name].Secrets {
			keys = append(keys, k)
		}
		sort.Strings(keys)
		for _, k := range keys {
			if u.Repos[name].Secrets[k].Plaintext() {
				warns = append(warns, fmt.Sprintf("secret %s for %s is stored as plaintext; prefer {cmd: ...} or {env: ...}", k, name))
			}
		}
	}
	return u, warns, nil
}
```

```go
package config

import (
	"bytes"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"path/filepath"
	"sort"

	"gopkg.in/yaml.v3"
)

// Repo is .github/homerun.yml. It is read from the commit under test, so it is
// untrusted: it may name secrets but never say how to obtain them.
type Repo struct {
	HostJobs    []string          `yaml:"host_jobs"`
	MaxParallel int               `yaml:"max_parallel"`
	Secrets     []string          `yaml:"secrets"`
	Checks      map[string]string `yaml:"checks"`
}

func LoadRepo(root string) (*Repo, error) {
	p := filepath.Join(root, ".github", "homerun.yml")
	b, err := os.ReadFile(p)
	if errors.Is(err, fs.ErrNotExist) {
		return &Repo{}, nil
	}
	if err != nil {
		return nil, err
	}
	r := &Repo{}
	dec := yaml.NewDecoder(bytes.NewReader(b))
	dec.KnownFields(true)
	if err := dec.Decode(r); err != nil && !errors.Is(err, io.EOF) {
		return nil, fmt.Errorf(".github/homerun.yml: %w", err)
	}
	return r, nil
}

func (r *Repo) CheckNames() []string {
	names := make([]string, 0, len(r.Checks))
	for n := range r.Checks {
		names = append(names, n)
	}
	sort.Strings(names)
	return names
}
```

```go
package mask

import (
	"sort"
	"strings"
)

type Masker struct{ r *strings.Replacer }

// New masks each secret, and each line of a multi-line secret, because tools
// often print one line of a key at a time.
func New(secrets []string) *Masker {
	seen := map[string]bool{}
	var vals []string
	add := func(v string) {
		if v != "" && !seen[v] {
			seen[v] = true
			vals = append(vals, v)
		}
	}
	for _, s := range secrets {
		add(s)
		if strings.Contains(s, "\n") {
			for _, l := range strings.Split(s, "\n") {
				// Short lines such as PEM armour are not secret and would mask too much.
				if l = strings.TrimSpace(l); len(l) >= 8 && !strings.HasPrefix(l, "-----") {
					add(l)
				}
			}
		}
	}
	// strings.Replacer tries pairs in argument order, so longer secrets go first.
	sort.Slice(vals, func(i, j int) bool { return len(vals[i]) > len(vals[j]) })
	pairs := make([]string, 0, 2*len(vals))
	for _, v := range vals {
		pairs = append(pairs, v, "***")
	}
	return &Masker{strings.NewReplacer(pairs...)}
}

func (m *Masker) Mask(s string) string {
	if m == nil || m.r == nil {
		return s
	}
	return m.r.Replace(s)
}
```

```go
import (
	"fmt"
	"os"
	"path/filepath"
	"sort"

// StringList accepts a YAML sequence or a single scalar, as GitHub does.
type StringList []string

func (l *StringList) UnmarshalYAML(n *yaml.Node) error {
	if n.Kind == yaml.ScalarNode {
		*l = StringList{n.Value}
		return nil
	}
	var s []string
	if err := n.Decode(&s); err != nil {
		return err
	}
	*l = s
	return nil
}

type Filter struct {
	Branches       StringList `yaml:"branches"`
	BranchesIgnore StringList `yaml:"branches-ignore"`
	Tags           StringList `yaml:"tags"`
	TagsIgnore     StringList `yaml:"tags-ignore"`
	Paths          StringList `yaml:"paths"`
	PathsIgnore    StringList `yaml:"paths-ignore"`
	Types          StringList `yaml:"types"`
}

type Job struct {
	ID   string
	Name string
}

type Workflow struct {
	Path string // relative to the repo root
	Name string
	On   map[string]*Filter // a nil filter means the event has no filters
	Jobs []Job
}

func LoadDir(root string) ([]*Workflow, error) {
	var rels []string
	for _, pat := range []string{"*.yml", "*.yaml"} {
		m, err := filepath.Glob(filepath.Join(root, ".github", "workflows", pat))
		if err != nil {
			return nil, err
		}
		for _, p := range m {
			rel, _ := filepath.Rel(root, p)
			rels = append(rels, filepath.ToSlash(rel))
		}
	}
	sort.Strings(rels)
	out := make([]*Workflow, 0, len(rels))
	for _, rel := range rels {
		w, err := Load(root, rel)
		if err != nil {
			return nil, err
		}
		out = append(out, w)
	}
	return out, nil
}

func Load(root, rel string) (*Workflow, error) {
	b, err := os.ReadFile(filepath.Join(root, rel))
	if err != nil {
		return nil, err
	}
	var doc struct {
		Name string    `yaml:"name"`
		On   yaml.Node `yaml:"on"`
		Jobs yaml.Node `yaml:"jobs"`
	}
	if err := yaml.Unmarshal(b, &doc); err != nil {
		return nil, fmt.Errorf("%s: %w", rel, err)
	}
	w := &Workflow{Path: rel, Name: doc.Name, On: map[string]*Filter{}}
	if w.Name == "" {
		w.Name = rel // GitHub shows the file path for unnamed workflows
	}
	switch doc.On.Kind {
	case yaml.ScalarNode:
		w.On[doc.On.Value] = nil
	case yaml.SequenceNode:
		for _, n := range doc.On.Content {
			w.On[n.Value] = nil
		}
	case yaml.MappingNode:
		for i := 0; i+1 < len(doc.On.Content); i += 2 {
			ev, val := doc.On.Content[i].Value, doc.On.Content[i+1]
			var f *Filter
			if val.Kind == yaml.MappingNode {
				f = &Filter{}
				if err := val.Decode(f); err != nil {
					return nil, fmt.Errorf("%s: on.%s: %w", rel, ev, err)
				}
			}
			w.On[ev] = f
		}
	default:
		return nil, fmt.Errorf("%s: missing 'on'", rel)
	}
	for i := 0; i+1 < len(doc.Jobs.Content); i += 2 {
		id := doc.Jobs.Content[i].Value
		var j struct {
			Name string `yaml:"name"`
		}
		if err := doc.Jobs.Content[i+1].Decode(&j); err != nil {
			return nil, fmt.Errorf("%s: jobs.%s: %w", rel, id, err)
		}
		name := j.Name
		// ponytail: expression names are not evaluated; the id is stable and unique. Evaluate if users ask.
		if name == "" || strings.Contains(name, "${{") {
			name = id
		}
		w.Jobs = append(w.Jobs, Job{ID: id, Name: name})
	}
	return w, nil
}

func (w *Workflow) Handles() bool {
	_, push := w.On["push"]
	_, pr := w.On["pull_request"]
	return push || pr
}

func (w *Workflow) Job(id string) (Job, bool) {
	for _, j := range w.Jobs {
		if j.ID == id {
			return j, true
		}
	}
	return Job{}, false
}
```

```go
package workflow

import (
	"regexp"
	"slices"
	"strings"
)

func (w *Workflow) Matches(event, ref, action string, changed []string) bool {
	f, ok := w.On[event]
	if !ok {
		return false
	}
	if f == nil {
		return true
	}
	if event == "pull_request" && len(f.Types) > 0 && !slices.Contains(f.Types, action) {
		return false
	}
	return refOK(event, ref, f) && pathsOK(f, changed)
}

func refOK(event, ref string, f *Filter) bool {
	if event == "pull_request" {
		return filterList(ref, f.Branches, f.BranchesIgnore)
	}
	hasBranch := f.Branches != nil || f.BranchesIgnore != nil
	hasTag := f.Tags != nil || f.TagsIgnore != nil
	if tag, ok := strings.CutPrefix(ref, "refs/tags/"); ok {
		// GitHub: filtering only branches means tag pushes never match, and vice versa.
		if !hasTag {
			return !hasBranch
		}
		return filterList(tag, f.Tags, f.TagsIgnore)
	}
	if !hasBranch {
		return !hasTag
	}
	return filterList(strings.TrimPrefix(ref, "refs/heads/"), f.Branches, f.BranchesIgnore)
}

func filterList(name string, include, ignore []string) bool {
	if include != nil {
		return matchList(name, include)
	}
	if ignore != nil {
		return !matchList(name, ignore)
	}
	return true
}

func pathsOK(f *Filter, changed []string) bool {
	if changed == nil || (f.Paths == nil && f.PathsIgnore == nil) {
		return true
	}
	if f.Paths != nil {
		for _, c := range changed {
			if matchList(c, f.Paths) {
				return true
			}
		}
		return false
	}
	for _, c := range changed {
		if !matchList(c, f.PathsIgnore) {
			return true
		}
	}
	return false
}

// matchList applies patterns in order; a later "!pattern" can exclude an earlier match.
func matchList(name string, patterns []string) bool {
	matched := false
	for _, p := range patterns {
		if neg, ok := strings.CutPrefix(p, "!"); ok {
			if matchGlob(neg, name) {
				matched = false
			}
		} else if matchGlob(p, name) {
			matched = true
		}
	}
	return matched
}

// matchGlob implements GitHub's filter pattern syntax, where "**.md" matches at
// any depth (unlike shell globs) and ? and + quantify the preceding character.
// ponytail: compiles per call; cache compiled patterns if polling many repos shows it in a profile.
func matchGlob(pattern, name string) bool {
	var b strings.Builder
	b.WriteString("^")
	for i := 0; i < len(pattern); i++ {
		switch c := pattern[i]; c {
		case '*':
			switch {
			case strings.HasPrefix(pattern[i:], "**/"):
				b.WriteString("(.*/)?")
				i += 2
			case strings.HasPrefix(pattern[i:], "**"):
				b.WriteString(".*")
				i++
			default:
				b.WriteString("[^/]*")
			}
		case '?', '+':
			b.WriteByte(c)
		case '[':
			if j := strings.IndexByte(pattern[i:], ']'); j > 0 {
				b.WriteString(pattern[i : i+j+1])
				i += j
			} else {
				b.WriteString(`\[`)
			}
		case '\\':
			if i+1 < len(pattern) {
				b.WriteString(regexp.QuoteMeta(pattern[i+1 : i+2]))
				i++
			}
		default:
			b.WriteString(regexp.QuoteMeta(string(c)))
		}
	}
	b.WriteString("$")
	re, err := regexp.Compile(b.String())
	return err == nil && re.MatchString(name)
}
```

```go
package workflow

import (
	"fmt"
	"os"
	"slices"

	"gopkg.in/yaml.v3"
)

// HostLabel is the runs-on label homerun maps to act's -self-hosted platform.
// act's -P maps labels, not jobs, so host jobs get a label of their own.
const HostLabel = "homerun-host"

// PrepareJobs edits a workflow in the snapshot (never the user's checkout):
// host jobs run on the host, disabled jobs get "if: false" so act skips them.
func PrepareJobs(path string, host, disable []string) error {
	if len(host) == 0 && len(disable) == 0 {
		return nil
	}
	b, err := os.ReadFile(path)
	if err != nil {
		return err
	}
	var doc yaml.Node
	if err := yaml.Unmarshal(b, &doc); err != nil {
		return fmt.Errorf("%s: %w", path, err)
	}
	if len(doc.Content) == 0 {
		return fmt.Errorf("%s: empty workflow", path)
	}
	jobs := mapGet(doc.Content[0], "jobs")
	if jobs == nil {
		return nil
	}
	for i := 0; i+1 < len(jobs.Content); i += 2 {
		id, job := jobs.Content[i].Value, jobs.Content[i+1]
		switch {
		case slices.Contains(disable, id):
			mapSet(job, "if", "false")
		case slices.Contains(host, id):
			mapSet(job, "runs-on", HostLabel)
		}
	}
	out, err := yaml.Marshal(&doc)
	if err != nil {
		return err
	}
	return os.WriteFile(path, out, 0o644)
}

func mapGet(m *yaml.Node, key string) *yaml.Node {
	if m.Kind != yaml.MappingNode {
		return nil
	}
	for i := 0; i+1 < len(m.Content); i += 2 {
		if m.Content[i].Value == key {
			return m.Content[i+1]
		}
	}
	return nil
}

func mapSet(m *yaml.Node, key, val string) {
	v := &yaml.Node{Kind: yaml.ScalarNode, Value: val}
	for i := 0; i+1 < len(m.Content); i += 2 {
		if m.Content[i].Value == key {
			m.Content[i+1] = v
			return
		}
	}
	m.Content = append(m.Content, &yaml.Node{Kind: yaml.ScalarNode, Value: key}, v)
}
```

```go
package event

import (
	"encoding/json"
	"fmt"
	"strings"
)

const Zero = "0000000000000000000000000000000000000000"

// PRAction is the action homerun reports for every PR run: it cannot tell
// "opened" from "synchronize" by polling, and synchronize is the common case.
const PRAction = "synchronize"

type Event struct {
	Name          string `json:"name"` // push | pull_request
	Repo          string `json:"repo"`
	DefaultBranch string `json:"default_branch"`
	SHA           string `json:"sha"`
	Ref           string `json:"ref,omitempty"`
	Before        string `json:"before,omitempty"`
	PR            int    `json:"pr,omitempty"`
	Title         string `json:"title,omitempty"`
	HeadRef       string `json:"head_ref,omitempty"`
	BaseRef       string `json:"base_ref,omitempty"`
	BaseSHA       string `json:"base_sha,omitempty"`
	HeadRepo      string `json:"head_repo,omitempty"`
	Fork          bool   `json:"fork,omitempty"`
}

func ForPR(repo, defaultBranch string, pr int, title, headRef, headSHA, headRepo, baseRef, baseSHA string) Event {
	return Event{
		Name: "pull_request", Repo: repo, DefaultBranch: defaultBranch, SHA: headSHA,
		PR: pr, Title: title, HeadRef: headRef, BaseRef: baseRef, BaseSHA: baseSHA, HeadRepo: headRepo,
		// A deleted fork has no head repo; it must not inherit the base repo's trust.
		Fork: headRepo == "" || !strings.EqualFold(headRepo, repo),
	}
}

func (e Event) Key() string {
	if e.Name == "pull_request" {
		return fmt.Sprintf("pull_request:%d", e.PR)
	}
	return "push:" + e.Ref
}

func (e Event) FilterRef() string {
	if e.Name == "pull_request" {
		return e.BaseRef
	}
	return e.Ref
}

func (e Event) Payload() ([]byte, error) {
	owner, name, _ := strings.Cut(e.Repo, "/")
	repo := map[string]any{
		"full_name": e.Repo, "name": name, "owner": map[string]any{"login": owner},
		"default_branch": e.DefaultBranch, "html_url": "https://github.com/" + e.Repo,
	}
	if e.Name == "pull_request" {
		return json.Marshal(map[string]any{
			"action": PRAction, "number": e.PR, "repository": repo,
			"pull_request": map[string]any{
				"number": e.PR, "title": e.Title,
```

```go
package actlog

import (
	"encoding/json"
	"fmt"
	"sort"
	"strings"
)

type Kind int

const (
	Line Kind = iota
	Started
	Finished
)

type Event struct {
	Kind       Kind
	JobID      string
	Matrix     map[string]any
	Leg        string // "" for lines not tied to a job
	Text       string // Line only
	Conclusion string // Finished only
	FailedStep string // Finished only
}

type entry struct {
	JobID      string         `json:"jobID"`
	Matrix     map[string]any `json:"matrix"`
	Msg        string         `json:"msg"`
	Step       string         `json:"step"`
	StepResult string         `json:"stepResult"`
	JobResult  string         `json:"jobResult"`
}

// Parser turns act --json output into per-leg events. Mask is applied to
// every string it emits because act leaves secrets unmasked in "step".
type Parser struct {
	Mask    func(string) string
	started map[string]bool
	failed  map[string]string
}

func (p *Parser) mask(s string) string {
	if p.Mask == nil {
		return s
	}
	return p.Mask(s)
}

func (p *Parser) Feed(line []byte) []Event {
	if p.started == nil {
		p.started, p.failed = map[string]bool{}, map[string]string{}
	}
	var e entry
	if json.Unmarshal(line, &e) != nil || e.JobID == "" {
		return []Event{{Kind: Line, Text: p.mask(strings.TrimRight(string(line), "\r\n"))}}
	}
	leg := LegKey(e.JobID, e.Matrix)
	var out []Event
	if !p.started[leg] {
		p.started[leg] = true
		out = append(out, Event{Kind: Started, JobID: e.JobID, Matrix: e.Matrix, Leg: leg})
	}
	for _, l := range strings.Split(strings.TrimRight(e.Msg, "\n"), "\n") {
		out = append(out, Event{Kind: Line, JobID: e.JobID, Matrix: e.Matrix, Leg: leg, Text: p.mask(l)})
	}
	if e.StepResult == "failure" && p.failed[leg] == "" {
		p.failed[leg] = p.mask(e.Step)
	}
	if e.JobResult != "" {
		c := e.JobResult
		// act stamps the whole matrix job's result on every leg; a leg with no failed step passed.
		if c == "failure" && len(e.Matrix) > 0 && p.failed[leg] == "" {
			c = "success"
		}
		out = append(out, Event{Kind: Finished, JobID: e.JobID, Matrix: e.Matrix, Leg: leg, Conclusion: c, FailedStep: p.failed[leg]})
	}
	return out
}

func LegKey(jobID string, matrix map[string]any) string {
	if len(matrix) == 0 {
		return jobID
	}
	b, _ := json.Marshal(matrix) // map keys marshal sorted, so the key is stable
	return jobID + " " + string(b)
}

// LegName mimics GitHub's "job (v1, v2)". ponytail: values in key order, not
// matrix declaration order; fine for names, revisit if users find it confusing.
func LegName(jobName string, matrix map[string]any) string {
	if len(matrix) == 0 {
		return jobName
	}
	keys := make([]string, 0, len(matrix))
	for k := range matrix {
		keys = append(keys, k)
	}
	sort.Strings(keys)
	vals := make([]string, len(keys))
	for i, k := range keys {
		vals[i] = fmt.Sprint(matrix[k])
	}
	return jobName + " (" + strings.Join(vals, ", ") + ")"
}
```

```go
package git

import (
	"bytes"
	"context"
	"encoding/base64"
	"errors"
	"fmt"
	"io/fs"
	"os"
	"os/exec"
	"path/filepath"
	"strings"
	"sync"
)

const zero = "0000000000000000000000000000000000000000"

type Mirror struct {
	Dir string // bare mirror
	URL string
	mu  sync.Mutex
}

func run(ctx context.Context, env []string, dir string, args ...string) (string, error) {
	cmd := exec.CommandContext(ctx, "git", args...)
	cmd.Dir = dir
	cmd.Env = append(os.Environ(), append([]string{"GIT_TERMINAL_PROMPT=0"}, env...)...)
	var stderr bytes.Buffer
	cmd.Stderr = &stderr
	out, err := cmd.Output()
	if err != nil {
		return "", fmt.Errorf("git %s: %w: %s", args[0], err, strings.TrimSpace(stderr.String()))
	}
	return strings.TrimSpace(string(out)), nil
}

// authEnv hands git the token through environment config so it never appears
// in argv (visible in ps) or in the mirror's config file.
func authEnv(token string) []string {
	if token == "" {
		return nil
	}
	cred := base64.StdEncoding.EncodeToString([]byte("x-access-token:" + token))
	return []string{
		"GIT_CONFIG_COUNT=1",
		"GIT_CONFIG_KEY_0=http.https://github.com/.extraheader",
		"GIT_CONFIG_VALUE_0=Authorization: Basic " + cred,
	}
}

func (m *Mirror) Fetch(ctx context.Context, token string) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	if _, err := os.Stat(m.Dir); errors.Is(err, fs.ErrNotExist) {
		if err := os.MkdirAll(filepath.Dir(m.Dir), 0o755); err != nil {
			return err
		}
		_, err := run(ctx, authEnv(token), "", "clone", "--mirror", "--quiet", m.URL, m.Dir)
		return err
	}
	_, err := run(ctx, authEnv(token), m.Dir, "fetch", "--prune", "--quiet", "origin")
	return err
}

func (m *Mirror) AddWorktree(ctx context.Context, sha, dir string) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	_, err := run(ctx, nil, m.Dir, "worktree", "add", "--detach", "--quiet", dir, sha)
	return err
}

func (m *Mirror) RemoveWorktree(ctx context.Context, dir string) error {
	m.mu.Lock()
	defer m.mu.Unlock()
	_, err := run(ctx, nil, m.Dir, "worktree", "remove", "--force", dir)
	if err != nil {
		// A half-created worktree may not be registered; remove the directory anyway.
		os.RemoveAll(dir)
	}
	_, _ = run(ctx, nil, m.Dir, "worktree", "prune")
	return nil
}

func (m *Mirror) ChangedFiles(ctx context.Context, base, head string) ([]string, error) {
	if base == "" || base == zero {
		return nil, nil
	}
	out, err := run(ctx, nil, m.Dir, "diff", "--name-only", base+"..."+head)
	if err != nil {
		return nil, err
	}
	files := []string{}
	for _, l := range strings.Split(out, "\n") {
		if l != "" {
			files = append(files, l)
		}
	}
	return files, nil
}

func (m *Mirror) RevParse(ctx context.Context, ref string) (string, error) {
	return run(ctx, nil, m.Dir, "rev-parse", "--verify", ref+"^{commit}")
}
```

```go
	Worktree string      `json:"worktree"`

	b := make([]byte, 3)
	rand.Read(b)
	return time.Now().UTC().Format("20060102T150405") + "-" + hex.EncodeToString(b)
}

func (s *Store) RunDir(id string) string  { return filepath.Join(s.Dir, "runs", id) }
func (s *Store) LogPath(id string) string { return filepath.Join(s.RunDir(id), "log") }

func writeJSON(path string, v any) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o700); err != nil {
		return err
	}
	b, err := json.MarshalIndent(v, "", "  ")
	if err != nil {
		return err
	}
	tmp := path + ".tmp"
	if err := os.WriteFile(tmp, b, 0o600); err != nil {
		return err
	}
	return os.Rename(tmp, path)
}

func (s *Store) Save(r *Run) error {
	return writeJSON(filepath.Join(s.RunDir(r.ID), "meta.json"), r)
}

func (s *Store) List() ([]*Run, error) {
	entries, err := os.ReadDir(filepath.Join(s.Dir, "runs"))
	if errors.Is(err, fs.ErrNotExist) {
		return nil, nil
	}
	if err != nil {
		return nil, err
	}
	var runs []*Run
	for _, e := range entries {
		b, err := os.ReadFile(filepath.Join(s.RunDir(e.Name()), "meta.json"))
		if err != nil {
			continue // a run dir without meta is a crash leftover; Prune removes it eventually
		}
		r := &Run{}
		if json.Unmarshal(b, r) == nil {
			runs = append(runs, r)
		}
	}
	sort.Slice(runs, func(i, j int) bool { return runs[i].ID > runs[j].ID })
	return runs, nil
}

func (s *Store) Prune(maxAge time.Duration, now time.Time) error {
	runs, err := s.List()
	if err != nil {
		return err
	}
	for _, r := range runs {
		if now.Sub(r.Created) > maxAge && (r.Status == "done" || r.Status == "cancelled") {
			if err := os.RemoveAll(s.RunDir(r.ID)); err != nil {
				return err
			}
		}
	}
	return nil
}

func (s *Store) LoadState() (*State, error) {
	st := &State{Branches: map[string]map[string]string{}}
	b, err := os.ReadFile(filepath.Join(s.Dir, "state.json"))
	if errors.Is(err, fs.ErrNotExist) {
		return st, nil
	}
	if err != nil {
		return nil, err
	}
	if err := json.Unmarshal(b, st); err != nil {
		return nil, err
	}
	if st.Branches == nil {
		st.Branches = map[string]map[string]string{}
	}
	return st, nil
}

func (s *Store) SaveState(st *State) error {
	return writeJSON(filepath.Join(s.Dir, "state.json"), st)
}
```

```go
package sched

import (
	"context"
	"sync"
)

// Scheduler caps concurrent runs globally and per repo, and cancels a run when
// a newer one arrives for the same key (a PR or a branch).
// ponytail: one goroutine per waiting run and Go's channel wake-up order (roughly FIFO);
// add an explicit queue if users need strict ordering or priorities.
type Scheduler struct {
	slots chan int
	size  int
	mu    sync.Mutex
	repos map[string]chan struct{}
	byKey map[string]string
	byID  map[string]context.CancelFunc
}

func New(global int) *Scheduler {
	if global < 1 {
		global = 1
	}
	s := &Scheduler{slots: make(chan int, global), size: global,
		repos: map[string]chan struct{}{}, byKey: map[string]string{}, byID: map[string]context.CancelFunc{}}
	for i := 0; i < global; i++ {
		s.slots <- i
	}
	return s
}

func (s *Scheduler) Submit(parent context.Context, id, key, repo string, repoMax int, fn func(ctx context.Context, slot int)) {
	ctx, cancel := context.WithCancel(parent)
	s.mu.Lock()
	if key != "" {
		if prev, ok := s.byKey[key]; ok {
			s.byID[prev]()
		}
		s.byKey[key] = id
	}
	s.byID[id] = cancel
	sem := s.repos[repo]
	if sem == nil {
		if repoMax <= 0 {
			repoMax = s.size
		}
		sem = make(chan struct{}, repoMax)
		s.repos[repo] = sem
	}
	s.mu.Unlock()

	go func() {
		defer s.done(id, key, cancel)
		select {
		case sem <- struct{}{}:
		case <-ctx.Done():
			fn(ctx, -1)
			return
		}
		defer func() { <-sem }()
		select {
		case slot := <-s.slots:
			defer func() { s.slots <- slot }()
			// select picks randomly when a slot frees just as the run is cancelled.
			if ctx.Err() != nil {
				fn(ctx, -1)
				return
			}
			fn(ctx, slot)
		case <-ctx.Done():
			fn(ctx, -1)
		}
	}()
}

func (s *Scheduler) done(id, key string, cancel context.CancelFunc) {
	s.mu.Lock()
	delete(s.byID, id)
	if s.byKey[key] == id {
		delete(s.byKey, key)
	}
	s.mu.Unlock()
	cancel()
}

func (s *Scheduler) Cancel(id string) bool {
	s.mu.Lock()
	defer s.mu.Unlock()
	cancel, ok := s.byID[id]
	if ok {
		cancel()
	}
	return ok
}
```

```go
package gh

import (
	"bytes"
	"io"
	"net/http"
	"sync"
)

// etagTransport replays cached bodies on 304 so polling unchanged repos costs
// no rate limit. ponytail: whole cache dropped at 2000 entries; LRU if that ever churns.
type etagTransport struct {
	next  http.RoundTripper
	mu    sync.Mutex
	cache map[string]cached
}

type cached struct {
	etag   string
	header http.Header
	body   []byte
}

func (t *etagTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	if req.Method != http.MethodGet {
		return t.next.RoundTrip(req)
	}
	key := req.URL.String()
	t.mu.Lock()
	c, ok := t.cache[key]
	t.mu.Unlock()
	if ok {
		req = req.Clone(req.Context())
		req.Header.Set("If-None-Match", c.etag)
	}
	resp, err := t.next.RoundTrip(req)
	if err != nil {
		return nil, err
	}
	if ok && resp.StatusCode == http.StatusNotModified {
		resp.Body.Close()
		return &http.Response{
			Status: "200 OK", StatusCode: 200, Proto: resp.Proto, ProtoMajor: resp.ProtoMajor, ProtoMinor: resp.ProtoMinor,
			Header: c.header.Clone(), Body: io.NopCloser(bytes.NewReader(c.body)), ContentLength: int64(len(c.body)), Request: req,
		}, nil
	}
	if resp.StatusCode == http.StatusOK && resp.Header.Get("ETag") != "" {
		body, err := io.ReadAll(resp.Body)
		resp.Body.Close()
		if err != nil {
			return nil, err
		}
		t.mu.Lock()
		if t.cache == nil || len(t.cache) > 2000 {
			t.cache = map[string]cached{}
		}
		t.cache[key] = cached{etag: resp.Header.Get("ETag"), header: resp.Header.Clone(), body: body}
		t.mu.Unlock()
		resp.Body = io.NopCloser(bytes.NewReader(body))
	}
	return resp, nil
}
```

```go
package gh

import (
	"context"
	"errors"
	"net/http"
	"strings"
	"time"
	"unicode/utf8"

	"github.com/google/go-github/v92/github"
)

// Retry backs off for up to ~3 minutes on errors that a later attempt can fix:
// network failures, 5xx and rate limits.
func Retry(ctx context.Context, fn func() error) error {
	delay := time.Second
	for attempt := 0; ; attempt++ {
		err := fn()
		if err == nil || attempt == 7 || !retryable(err) {
			return err
		}
		select {
		case <-time.After(delay):
		case <-ctx.Done():
			return ctx.Err()
		}
		delay = min(delay*2, time.Minute)
	}
}

func retryable(err error) bool {
	var rl *github.RateLimitError
	var abuse *github.AbuseRateLimitError
	if errors.As(err, &rl) || errors.As(err, &abuse) {
		return true
	}
	var e *github.ErrorResponse
	if errors.As(err, &e) && e.Response != nil {
		return e.Response.StatusCode >= 500 || e.Response.StatusCode == http.StatusTooManyRequests
	}
	return true // transport errors
}

func Truncate(s string, n int) string {
	if len(s) <= n {
		return s
	}
	const mark = "…"
	tail := s[len(s)-(n-len(mark)):]
	for len(tail) > 0 && !utf8.RuneStart(tail[0]) {
		tail = tail[1:]
	}
	return mark + strings.ToValidUTF8(tail, "")
}
```

```go
func SocketPath() string {
	if d := os.Getenv("XDG_RUNTIME_DIR"); d != "" {
		return filepath.Join(d, "homerun.sock")
	}
	return filepath.Join(os.TempDir(), fmt.Sprintf("homerun-%d.sock", os.Getuid()))

	return &Client{hc: &http.Client{Transport: &http.Transport{
		DialContext: func(ctx context.Context, _, _ string) (net.Conn, error) {
			var d net.Dialer
			return d.DialContext(ctx, "unix", sock)
		},
	}}}
}

func (c *Client) req(ctx context.Context, method, path string, body any) (*http.Response, error) {
	var r io.Reader
	if body != nil {
		b, err := json.Marshal(body)
		if err != nil {
			return nil, err
		}
		r = bytes.NewReader(b)
	}
	req, err := http.NewRequestWithContext(ctx, method, "http://homerun"+path, r)
	if err != nil {
		return nil, err

	if err != nil {
		return nil, fmt.Errorf("homerun daemon not reachable (is it running? start it with: homerun daemon): %w", err)
	}
	if resp.StatusCode >= 300 {
		msg, _ := io.ReadAll(resp.Body)
		resp.Body.Close()
		return nil, fmt.Errorf("%s", strings.TrimSpace(string(msg)))
	}
	return resp, nil
}

	if err != nil {
		return err

	if out != nil {
		return json.NewDecoder(resp.Body).Decode(out)
	}
	return nil
```

```go
func (h *harness) git(args ...string) string {
	h.t.Helper()
	cmd := exec.Command("git", args...)
	if h.src != "" && args[0] != "init" {
		cmd.Dir = h.src
	}
	cmd.Env = append(os.Environ(), "GIT_AUTHOR_NAME=t", "GIT_AUTHOR_EMAIL=t@t", "GIT_COMMITTER_NAME=t", "GIT_COMMITTER_EMAIL=t@t")
	out, err := cmd.CombinedOutput()
	if err != nil {
		h.t.Fatalf("git %v: %v\n%s", args, err, out)
	}
	return strings.TrimSpace(string(out))
}

// commit writes files (path -> body) into the source repo and returns the new sha.
func (h *harness) commit(files map[string]string) string {
	h.t.Helper()
	for p, body := range files {
		full := filepath.Join(h.src, p)
		os.MkdirAll(filepath.Dir(full), 0o755)
		os.WriteFile(full, []byte(body), 0o644)
	}
	h.git("add", "-A")
	h.git("commit", "-qm", "c", "--allow-empty", "--no-gpg-sign")
	return h.git("rev-parse", "HEAD")
}

// push commits to main and points the fake GitHub at it.
func (h *harness) push(files map[string]string) string {
	sha := h.commit(files)
	h.fake.SetBranch(repo, "main", sha)
	return sha
}

	os.WriteFile(p, []byte(s), 0o644)
	h.t.Setenv("FAKE_ACT_OUTPUT", p)
}

// waitDone waits until sha has check runs and all of them are completed.
func (h *harness) waitDone(sha string) map[string]*gh.FakeCheck {
	h.t.Helper()
	deadline := time.Now().Add(15 * time.Second)
	for {
		cs := h.fake.Checks(repo, sha)
		done := len(cs) > 0
		for _, c := range cs {
			done = done && c.Status == "completed"
		}
		if done {
			out := map[string]*gh.FakeCheck{}
			for _, c := range cs {
				out[c.Name] = c
			}
			return out
		}
		if time.Now().After(deadline) {
			for _, c := range cs {
				h.t.Logf("%s: %s %s", c.Name, c.Status, c.Conclusion)
			}
			h.t.Fatalf("timeout waiting for checks on %s", sha)
		}
		time.Sleep(50 * time.Millisecond)
	}
}

func (h *harness) waitStatus(sha, name, status string) {
	h.t.Helper()
	deadline := time.Now().Add(15 * time.Second)
	for time.Now().Before(deadline) {
		for _, c := range h.fake.Checks(repo, sha) {
			if c.Name == name && c.Status == status {
				return
			}
		}
		time.Sleep(50 * time.Millisecond)
	}
	h.t.Fatalf("timeout waiting for %s to be %s", name, status)
}
```

```go
package daemon

import (
	"context"
	"errors"
	"fmt"
	"log/slog"
	"path/filepath"
	"sort"
	"strings"
	"sync"
	"time"

	"github.com/matthew-reed-holden/homerun/internal/api"
	"github.com/matthew-reed-holden/homerun/internal/config"
	"github.com/matthew-reed-holden/homerun/internal/event"
	"github.com/matthew-reed-holden/homerun/internal/gh"
	"github.com/matthew-reed-holden/homerun/internal/git"
	"github.com/matthew-reed-holden/homerun/internal/runner"
	"github.com/matthew-reed-holden/homerun/internal/sched"
	"github.com/matthew-reed-holden/homerun/internal/store"
	"github.com/matthew-reed-holden/homerun/internal/workflow"
)

type Options struct {
	Config     *config.User
	ConfigPath string
	Source     gh.Source
	Reporter   gh.Reporter
	AppID      int64
	StateDir   string
	Act        string
	GitURL     func(repo string) string // nil means https://github.com/<repo>.git
}

type Daemon struct {
	opts   Options
	store  *store.Store
	runner *runner.Runner
	sched  *sched.Scheduler
	base   context.Context // parent of every run; cancelled when Run returns
	stop   context.CancelFunc

	mu        sync.Mutex
	cfg       *config.User
	state     *store.State
	seen      map[string]string // repo|event key -> sha already handled
	runs      map[string]*store.Run
	views     map[string]*api.Repo
	unhandled map[string][]string
	mirrors   map[string]*git.Mirror
	repoLocks map[string]*sync.Mutex
	lastPrune time.Time
}

type plan struct {
	repo      *config.Repo
	workflows []*workflow.Workflow
}

func New(o Options) (*Daemon, error) {
	if o.GitURL == nil {
		o.GitURL = func(r string) string { return "https://github.com/" + r + ".git" }
	}
	st := &store.Store{Dir: o.StateDir}
	state, err := st.LoadState()
	if err != nil {
		return nil, err
	}
	base, stop := context.WithCancel(context.Background())
	return &Daemon{
		opts: o, store: st, state: state, cfg: o.Config, base: base, stop: stop,
		runner:    &runner.Runner{Act: o.Act, Platforms: o.Config.Platforms, CacheRoot: filepath.Join(o.StateDir, "act-cache")},
		sched:     sched.New(o.Config.MaxParallel),
		seen:      map[string]string{},
		runs:      map[string]*store.Run{},
		views:     map[string]*api.Repo{},
		unhandled: map[string][]string{},
		mirrors:   map[string]*git.Mirror{},
		repoLocks: map[string]*sync.Mutex{},
	}, nil
}

func CheckName(workflow, job string) string { return "homerun / " + workflow + " / " + job }

func (d *Daemon) config() *config.User {
	d.mu.Lock()
	defer d.mu.Unlock()
	return d.cfg
}

// Reload re-reads the user config. max_parallel and platforms apply after a restart.
func (d *Daemon) Reload() error {
	cfg, warns, err := config.LoadUser(d.opts.ConfigPath)
	if err != nil {
		return err
	}
	for _, w := range warns {
		slog.Warn(w)
	}
	d.mu.Lock()
	d.cfg = cfg
	d.mu.Unlock()
	return nil
}

func (d *Daemon) Run(ctx context.Context) error {
	defer d.stop()
	d.recover(ctx)
	t := time.NewTicker(time.Duration(d.config().PollInterval))
	defer t.Stop()
	for {
		d.PollAll(ctx)
		select {
		case <-ctx.Done():
			return nil
		case <-t.C:
		}
	}
}

func (d *Daemon) PollAll(ctx context.Context) {
	cfg := d.config()
	names := make([]string, 0, len(cfg.Repos))
	for n := range cfg.Repos {
		names = append(names, n)
	}
	sort.Strings(names)
	for _, r := range names {
		err := d.pollRepo(ctx, r)
		if err != nil {
			slog.Error("poll failed", "repo", r, "err", err)
		}
		d.setRepoError(r, err)
	}
	if time.Since(d.lastPrune) > 24*time.Hour {
		d.lastPrune = time.Now()
		if err := d.store.Prune(time.Duration(cfg.Retain), time.Now()); err != nil {
			slog.Warn("prune failed", "err", err)
		}
		d.forgetOld(time.Duration(cfg.Retain))
	}
}

func (d *Daemon) pollRepo(ctx context.Context, repo string) error {
	src := d.opts.Source
	def, err := src.DefaultBranch(ctx, repo)
	if err != nil {
		return err
	}
	branches, err := src.Branches(ctx, repo)
	if err != nil {
		return err
	}
	prs, err := src.PullRequests(ctx, repo)
	if err != nil {
		return err
	}

	var pushes []event.Event
	d.mu.Lock()
	known, baselined := d.state.Branches[repo]
	if !baselined {
		known = map[string]string{}
		d.state.Branches[repo] = known
	}
	current := map[string]bool{}
	for _, b := range branches {
		current[b.Ref] = true
		before, ok := known[b.Ref]
		switch {
		case !baselined:
			known[b.Ref] = b.SHA // heads that existed before registration are history, not work
		case ok && before == b.SHA:
		default:
			if !ok {
				before = event.Zero
			}
			pushes = append(pushes, event.Event{Name: "push", Repo: repo, DefaultBranch: def, SHA: b.SHA, Ref: "refs/heads/" + b.Ref, Before: before})
		}
	}
	for b := range known {
		if !current[b] {
			delete(known, b)
		}
	}
	err = d.store.SaveState(d.state)
	d.mu.Unlock()
	if err != nil {
		return err
	}

	view := &api.Repo{Name: repo}
	for _, b := range branches {
		if b.Ref != def {
			continue
		}
		checks, err := src.CheckRuns(ctx, repo, b.SHA)
		if err != nil {
			return err
		}
		view.Items = append(view.Items, api.Item{Label: def, Ref: def, SHA: b.SHA,
			URL: "https://github.com/" + repo + "/tree/" + def, Checks: apiChecks(checks)})
	}
	for _, ev := range pushes {
		checks, err := src.CheckRuns(ctx, repo, ev.SHA)
		if err != nil {
			return err
		}
		if err := d.handle(ctx, ev, checks); err != nil {
			slog.Error("could not start run", "repo", repo, "event", ev.Key(), "sha", ev.SHA, "err", err)
		}
	}
	for _, p := range prs {
		ev := event.ForPR(repo, def, p.PR, p.Title, p.Ref, p.SHA, p.HeadRepo, p.BaseRef, p.BaseSHA)
		checks, err := src.CheckRuns(ctx, repo, ev.SHA)
		if err != nil {
			return err
		}
		view.Items = append(view.Items, api.Item{Label: fmt.Sprintf("PR #%d %s", p.PR, p.Title), PR: p.PR, Ref: p.Ref,
			SHA: p.SHA, URL: p.URL, Checks: apiChecks(checks)})
		if err := d.handle(ctx, ev, checks); err != nil {
			slog.Error("could not start run", "repo", repo, "event", ev.Key(), "sha", ev.SHA, "err", err)
		}
	}
	d.mu.Lock()
	d.views[repo] = view
	d.mu.Unlock()
	return nil
}

func apiChecks(cs []gh.Check) []api.Check {
	out := make([]api.Check, len(cs))
	for i, c := range cs {
		out[i] = api.Check{Name: c.Name, Status: c.Status, Conclusion: c.Conclusion, URL: c.URL}
	}
	return out
}

// handle starts a run for ev unless homerun already claimed this commit for this
// event. The claim lives on GitHub, so restarts and other machines see it too.
func (d *Daemon) handle(ctx context.Context, ev event.Event, checks []gh.Check) error {
	k := ev.Repo + "|" + ev.Key()
	d.mu.Lock()
	done := d.seen[k] == ev.SHA
	d.mu.Unlock()
	if done {
		return nil
	}
	if !claimed(checks, d.opts.AppID, ev.Key()) {
		if _, err := d.Start(ctx, ev); err != nil {
			return err
		}
	}
	d.mu.Lock()
	defer d.mu.Unlock()
	d.seen[k] = ev.SHA
	if ev.Name == "push" {
		d.state.Branches[ev.Repo][strings.TrimPrefix(ev.Ref, "refs/heads/")] = ev.SHA
		return d.store.SaveState(d.state)
	}
	return nil
}

func claimed(checks []gh.Check, appID int64, key string) bool {
	for _, c := range checks {
		if c.AppID == appID && c.ExternalID == key {
			return true
		}
	}
	return false
}

func (d *Daemon) mirror(repo string) *git.Mirror {
	d.mu.Lock()
	defer d.mu.Unlock()
	m := d.mirrors[repo]
	if m == nil {
		m = &git.Mirror{Dir: filepath.Join(d.opts.StateDir, "mirrors", repo+".git"), URL: d.opts.GitURL(repo)}
		d.mirrors[repo] = m
	}
	return m
}

func (d *Daemon) repoLock(repo string) *sync.Mutex {
	d.mu.Lock()
	defer d.mu.Unlock()
	l := d.repoLocks[repo]
	if l == nil {
		l = &sync.Mutex{}
		d.repoLocks[repo] = l
	}
	return l
}

// Start snapshots ev's commit, decides what runs, creates queued check runs and
// queues the run. It returns a nil run when nothing in the repo listens to ev.
func (d *Daemon) Start(ctx context.Context, ev event.Event) (*store.Run, error) {
	lock := d.repoLock(ev.Repo)
	lock.Lock()
	defer lock.Unlock()
	m := d.mirror(ev.Repo)
	token, err := d.opts.Source.GitToken(ctx, ev.Repo)
	if err != nil {
		return nil, err
	}
	if err := m.Fetch(ctx, token); err != nil {
		return nil, err
	}
	run := &store.Run{ID: store.NewID(), Repo: ev.Repo, Event: ev, Status: "queued", Created: time.Now()}
	run.Worktree = filepath.Join(d.opts.StateDir, "work", run.ID)
	if err := m.AddWorktree(ctx, ev.SHA, run.Worktree); err != nil {
		return nil, d.failSetup(ctx, ev, err)
	}
	p, err := d.plan(ctx, m, run)
	if err != nil {
		m.RemoveWorktree(ctx, run.Worktree)
		return nil, d.failSetup(ctx, ev, err)
	}
	if len(run.Checks) == 0 {
		m.RemoveWorktree(ctx, run.Worktree)
		return nil, nil
	}
	for i, c := range run.Checks {
		err := gh.Retry(ctx, func() (err error) {
			c.ID, err = d.opts.Reporter.CreateCheck(ctx, ev.Repo, ev.SHA, c.Name, ev.Key())
			return err
		})
		if err != nil {
			// Close what was already created so no check run waits forever.
			for _, made := range run.Checks[:i] {
				d.opts.Reporter.UpdateCheck(ctx, ev.Repo, made.ID, gh.Update{Name: made.Name, Status: "completed",
					Conclusion: "cancelled", Title: "homerun could not start this run", Summary: "homerun error: " + err.Error()})
			}
			m.RemoveWorktree(ctx, run.Worktree)
			return nil, err
		}
		c.Status = "queued"
	}
	d.track(run)
	repoMax := p.repo.MaxParallel
	d.sched.Submit(d.base, run.ID, ev.Repo+"|"+ev.Key(), ev.Repo, repoMax, func(ctx context.Context, slot int) {
		d.execute(ctx, run, p, slot)
	})
	return run, nil
}

func (d *Daemon) plan(ctx context.Context, m *git.Mirror, run *store.Run) (*plan, error) {
	ev := run.Event
	rc, err := config.LoadRepo(run.Worktree)
	if err != nil {
		return nil, err
	}
	wfs, err := workflow.LoadDir(run.Worktree)
	if err != nil {
		return nil, err
	}
	changed, err := d.changedFiles(ctx, m, ev)
	if err != nil {
		slog.Warn("changed files unknown; paths filters will match", "repo", ev.Repo, "sha", ev.SHA, "err", err)
		changed = nil
	}
	p := &plan{repo: rc}
	var unhandled []string
	for _, w := range wfs {
		if !w.Handles() {
			unhandled = append(unhandled, w.Path)
			continue
		}
		if !w.Matches(ev.Name, ev.FilterRef(), event.PRAction, changed) {
			continue
		}
		p.workflows = append(p.workflows, w)
		for _, j := range w.Jobs {
			run.Checks = append(run.Checks, &store.Check{Name: CheckName(w.Name, j.Name), Workflow: w.Path, JobID: j.ID})
		}
	}
	for _, name := range rc.CheckNames() {
		run.Checks = append(run.Checks, &store.Check{Name: CheckName("checks", name), Extra: name})
	}
	d.mu.Lock()
	d.unhandled[ev.Repo] = unhandled
	d.mu.Unlock()
	return p, nil
}

func (d *Daemon) changedFiles(ctx context.Context, m *git.Mirror, ev event.Event) ([]string, error) {
	switch {
	case ev.Name == "pull_request":
		return m.ChangedFiles(ctx, ev.BaseSHA, ev.SHA)
	case ev.Before != event.Zero && ev.Before != "":
		return m.ChangedFiles(ctx, ev.Before, ev.SHA)
	case ev.Ref == "refs/heads/"+ev.DefaultBranch:
		return nil, nil
	default:
		// A new branch: compare with the default branch, as GitHub does.
		return m.ChangedFiles(ctx, "refs/heads/"+ev.DefaultBranch, ev.SHA)
	}
}

// failSetup reports a problem that stopped homerun before any job could run.
func (d *Daemon) failSetup(ctx context.Context, ev event.Event, cause error) error {
	msg := "homerun error: " + cause.Error()
	err := gh.Retry(ctx, func() error {
		id, err := d.opts.Reporter.CreateCheck(ctx, ev.Repo, ev.SHA, "homerun", ev.Key())
		if err != nil {
			return err
		}
		return d.opts.Reporter.UpdateCheck(ctx, ev.Repo, id, gh.Update{Name: "homerun", Status: "completed",
			Conclusion: "failure", Title: "homerun could not start this run", Summary: msg})
	})
	if err != nil {
		return errors.Join(cause, fmt.Errorf("reporting the failure: %w", err))
	}
	return cause
}

func (d *Daemon) track(run *store.Run) {
	d.mu.Lock()
	defer d.mu.Unlock()
	d.runs[run.ID] = run
	if err := d.store.Save(run); err != nil {
		slog.Warn("save run", "run", run.ID, "err", err)
	}
}

func (d *Daemon) forgetOld(maxAge time.Duration) {
	d.mu.Lock()
	defer d.mu.Unlock()
	for id, r := range d.runs {
		if time.Since(r.Created) > maxAge && (r.Status == "done" || r.Status == "cancelled") {
			delete(d.runs, id)
		}
	}
}

func (d *Daemon) setRepoError(repo string, err error) {
	d.mu.Lock()
	defer d.mu.Unlock()
	v := d.views[repo]
	if v == nil {
		v = &api.Repo{Name: repo}
		d.views[repo] = v
	}
	v.Error = ""

	}
}

	d.mu.Lock()
	defer d.mu.Unlock()
	run.Status = status

		slog.Warn("save run", "run", run.ID, "err", err)
	}
}

func (d *Daemon) addCheck(run *store.Run, c *store.Check) {
	d.mu.Lock()
	defer d.mu.Unlock()
	run.Checks = append(run.Checks, c)
}

// findCheck returns the check created at claim time for a workflow job.
func (d *Daemon) findCheck(run *store.Run, wf, jobID string) *store.Check {
	d.mu.Lock()
	defer d.mu.Unlock()
	for _, c := range run.Checks {
		if c.Workflow == wf && c.JobID == jobID && c.Leg == "" {
			return c
		}
	}
	return nil

// report updates a check locally and on GitHub. A failed report is logged, not
// fatal: the run continues and the next update carries the state forward.
func (d *Daemon) report(ctx context.Context, run *store.Run, c *store.Check, u gh.Update) {
	u.Name = c.Name
	d.mu.Lock()
	c.Status = u.Status
	if u.Conclusion != "" {
		c.Status, c.Conclusion = "completed", u.Conclusion
	}
	err := d.store.Save(run)
	d.mu.Unlock()
	if err != nil {
		slog.Warn("save run", "run", run.ID, "err", err)
	}
	if err := gh.Retry(ctx, func() error { return d.opts.Reporter.UpdateCheck(ctx, run.Repo, c.ID, u) }); err != nil {
		slog.Error("report check", "repo", run.Repo, "check", c.Name, "err", err)
	}
}

func (d *Daemon) complete(ctx context.Context, run *store.Run, c *store.Check, conclusion, title, summary, text string) {
	d.report(ctx, run, c, gh.Update{Status: "completed", Conclusion: conclusion, Title: title, Summary: summary, Text: text})
}

func (d *Daemon) closeWhere(ctx context.Context, run *store.Run, match func(*store.Check) bool, conclusion, summary, text string) {
	d.mu.Lock()
	var open []*store.Check
	for _, c := range run.Checks {
		if c.Status != "completed" && match(c) {
			open = append(open, c)
		}
	}
	d.mu.Unlock()
	for _, c := range open {
		d.complete(ctx, run, c, conclusion, summary, summary, text)
	}
}

func (d *Daemon) closeOpen(ctx context.Context, run *store.Run, conclusion, summary string) {
	d.closeWhere(ctx, run, func(*store.Check) bool { return true }, conclusion, summary, "")
}
```

```go
func (d *Daemon) execute(ctx context.Context, run *store.Run, p *plan, slot int) {
	// Reports must reach GitHub even when the run itself was cancelled.
	rctx := context.WithoutCancel(ctx)
	defer d.mirror(run.Repo).RemoveWorktree(rctx, run.Worktree)
	if slot < 0 || ctx.Err() != nil {
		d.closeOpen(rctx, run, "cancelled", cancelledText)

		return
	}

	fail := func(err error) {
		d.closeOpen(rctx, run, "failure", "homerun error: "+err.Error())
		d.setStatus(run, "done")
	}
	logf, err := os.OpenFile(d.store.LogPath(run.ID), os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0o600)
	if err != nil {
		fail(err)
		return
	}
	defer logf.Close()
	ev := run.Event
	secrets, err := d.secrets(ctx, run.Repo, p.repo, ev.Fork)
	if err != nil {
		fmt.Fprintf(logf, "[homerun] %v\n", err)
		fail(err)
		return
	}
	values := make([]string, 0, len(secrets))
	for _, v := range secrets {
		values = append(values, v)
	}
	mk := mask.New(values)
	evPath := filepath.Join(d.store.RunDir(run.ID), "event.json")
	payload, err := ev.Payload()
	if err == nil {
		err = os.WriteFile(evPath, payload, 0o600)
	}
	if err != nil {
		fail(err)
		return
	}

	host, disabled := p.repo.HostJobs, []string(nil)
	if ev.Fork {
		host, disabled = nil, p.repo.HostJobs
	}
	for _, w := range p.workflows {
		if ctx.Err() != nil {
			break
		}
		inWorkflow := func(c *store.Check) bool { return c.Workflow == w.Path }
		if err := workflow.PrepareJobs(filepath.Join(run.Worktree, w.Path), host, disabled); err != nil {
			d.closeWhere(rctx, run, inWorkflow, "failure", "homerun error: "+err.Error(), "")
			continue
		}
		for _, id := range disabled {
			d.closeWhere(rctx, run, func(c *store.Check) bool { return c.Workflow == w.Path && c.JobID == id }, "neutral", forkSkipped, "")
		}
		t := &tracker{d: d, ctx: rctx, run: run, wf: w, log: logf,

// secrets resolves the secrets a repo asks for. Fork PRs get none, as on GitHub.
func (d *Daemon) secrets(ctx context.Context, repo string, rc *config.Repo, fork bool) (map[string]string, error) {
	out := map[string]string{}
	if fork {
		return out, nil
	}
	configured := d.config().Repos[repo].Secrets
	for _, name := range rc.Secrets {
		s, ok := configured[name]
		if !ok {
			return nil, fmt.Errorf("secret %s is requested by .github/homerun.yml but not configured for %s in the homerun config", name, repo)
		}
		v, err := s.Resolve(ctx)
		if err != nil {
			return nil, fmt.Errorf("secret %s: %w", name, err)
		}
		out[name] = v
	}
	return out, nil
}

// tracker maps one act process's events onto check runs.
type tracker struct {
	d      *Daemon
	ctx    context.Context // reporting context; outlives cancellation
	run    *store.Run
	wf     *workflow.Workflow
	log    io.Writer
	legs   map[string]*store.Check   // leg key -> check
	tails  map[string][]string       // leg key -> last lines ("" = act's own output)
	matrix map[string][]*store.Check // job id -> leg checks
	failed bool
}

func (t *tracker) legName(e actlog.Event) string {
	name := e.JobID
	if j, ok := t.wf.Job(e.JobID); ok {
		name = j.Name
	}
	return actlog.LegName(name, e.Matrix)
}

func (t *tracker) handle(e actlog.Event) {
	switch e.Kind {
	case actlog.Line:
		prefix := "act"
		if e.Leg != "" {
			prefix = t.legName(e)
		}
		fmt.Fprintf(t.log, "[%s] %s\n", prefix, e.Text)
		tail := append(t.tails[e.Leg], e.Text)
		if len(tail) > tailLines {
			tail = tail[len(tail)-tailLines:]
		}
		t.tails[e.Leg] = tail
	case actlog.Started:
		t.start(e)
	case actlog.Finished:
		c := t.legs[e.Leg]
		if c == nil {
			return
		}
		if e.Conclusion == "failure" {
			t.failed = true
		}
		title, summary := "Succeeded", "Ran locally by homerun."
		if e.Conclusion != "success" {
			title, summary = strings.ToUpper(e.Conclusion[:1])+e.Conclusion[1:], "Ran locally by homerun."
			if e.FailedStep != "" {
				title, summary = "Failed at: "+e.FailedStep, "Failed step: `"+e.FailedStep+"`"
			}
		}
		t.d.complete(t.ctx, t.run, c, e.Conclusion, title, summary, codeBlock(t.tails[e.Leg]))
	}
}

func (t *tracker) start(e actlog.Event) {
	parent := t.d.findCheck(t.run, t.wf.Path, e.JobID)
	if parent == nil {
		return // a job homerun did not plan, e.g. one inside a reusable workflow
	}
	if len(e.Matrix) == 0 {
		t.legs[e.Leg] = parent
		t.d.report(t.ctx, t.run, parent, gh.Update{Status: "in_progress"})
		return
	}
	if len(t.matrix[e.JobID]) == 0 {
		t.d.report(t.ctx, t.run, parent, gh.Update{Status: "in_progress"})
	}
	c := &store.Check{Name: CheckName(t.wf.Name, t.legName(e)), Workflow: t.wf.Path, JobID: e.JobID, Leg: e.Leg}
	ev := t.run.Event
	err := gh.Retry(t.ctx, func() (err error) {
		c.ID, err = t.d.opts.Reporter.CreateCheck(t.ctx, ev.Repo, ev.SHA, c.Name, ev.Key())
		return err
	})
	if err != nil {
		fmt.Fprintf(t.log, "[homerun] could not create check %s: %v\n", c.Name, err)
		return
	}
	c.Status = "queued"
	t.d.addCheck(t.run, c)
	t.legs[e.Leg] = c
	t.matrix[e.JobID] = append(t.matrix[e.JobID], c)
	t.d.report(t.ctx, t.run, c, gh.Update{Status: "in_progress"})
}

// finish closes every check act never finished, then concludes matrix parents
// from their legs. A parent is never "skipped": GitHub counts skipped as passing.
func (t *tracker) finish(runCtx context.Context, actErr error) {
	conclusion, summary := "skipped", "Did not run: a job it needs failed, or its if: condition was false."
	switch {
	case runCtx.Err() != nil:
		conclusion, summary = "cancelled", cancelledText
	case actErr != nil && !t.failed:
		conclusion, summary = "failure", "homerun error: act exited without finishing this job: "+actErr.Error()
	}
	isParent := func(c *store.Check) bool { return c.Leg == "" && len(t.matrix[c.JobID]) > 0 }
	t.d.closeWhere(t.ctx, t.run, func(c *store.Check) bool { return c.Workflow == t.wf.Path && !isParent(c) },
		conclusion, summary, codeBlock(t.tails[""]))
	for jobID, legs := range t.matrix {
		parent := t.d.findCheck(t.run, t.wf.Path, jobID)
		worst, failed := "success", 0
		for _, l := range legs {
			switch l.Conclusion {
			case "failure", "timed_out":
				worst = "failure"
				failed++
			case "cancelled":
				if worst != "failure" {
					worst = "cancelled"
				}
			}
		}
		t.d.complete(t.ctx, t.run, parent, worst, fmt.Sprintf("%d of %d legs failed", failed, len(legs)),
			"Each matrix leg reports as its own check.", "")
	}
}

func (d *Daemon) runExtra(ctx, rctx context.Context, run *store.Run, c *store.Check, command string,
	secrets map[string]string, mk *mask.Masker, log io.Writer) {
	if ctx.Err() != nil {
		return // closed as cancelled by the caller
	}
	if run.Event.Fork {
		d.complete(rctx, run, c, "neutral", forkSkipped, forkSkipped, "")
		return
	}
	d.report(rctx, run, c, gh.Update{Status: "in_progress"})
	var tail []string
	w := &lineWriter{fn: func(l string) {
		l = mk.Mask(l)
		fmt.Fprintf(log, "[checks / %s] %s\n", c.Extra, l)
		if tail = append(tail, l); len(tail) > tailLines {
			tail = tail[1:]
		}
	}}
	cmd := exec.CommandContext(ctx, "sh", "-c", command)
	cmd.Dir = run.Worktree
	cmd.Env = os.Environ()
	for k, v := range secrets {
		cmd.Env = append(cmd.Env, k+"="+v)
	}
	cmd.Stdout, cmd.Stderr = w, w
	cmd.Cancel = func() error { return cmd.Process.Signal(os.Interrupt) }
	cmd.WaitDelay = 30 * time.Second
	err := cmd.Run()
	w.flush()
	conclusion, title := "success", "Succeeded"
	switch {
	case ctx.Err() != nil:
		conclusion, title = "cancelled", "Cancelled"
	case err != nil:
		conclusion, title = "failure", "Failed: "+err.Error()
	}
	d.complete(rctx, run, c, conclusion, title, "`"+mk.Mask(command)+"`", codeBlock(tail))
}

func codeBlock(lines []string) string {
	if len(lines) == 0 {
		return ""
	}
	return "```\n" + strings.Join(lines, "\n") + "\n```"
}

// lineWriter calls fn once per complete line, so masking never sees half a secret.
type lineWriter struct {
	buf []byte
	fn  func(string)
}

func (w *lineWriter) Write(p []byte) (int, error) {
	w.buf = append(w.buf, p...)
	for {
		i := bytes.IndexByte(w.buf, '\n')
		if i < 0 {
			return len(p), nil
		}
		w.fn(strings.TrimRight(string(w.buf[:i]), "\r"))
		w.buf = w.buf[i+1:]
	}
}

func (w *lineWriter) flush() {
	if len(w.buf) > 0 {
		w.fn(string(w.buf))
		w.buf = nil
	}
}
```

```go
// recover closes check runs stranded by a daemon that stopped mid-run, then
// re-queues those runs. Starting fresh is simpler and safer than resuming act.
func (d *Daemon) recover(ctx context.Context) {
	runs, err := d.store.List()
	if err != nil {
		slog.Error("reading run history", "err", err)
		return
	}
	d.mu.Lock()
	for _, r := range runs {
		d.runs[r.ID] = r
	}
	d.mu.Unlock()
	for _, r := range runs {
		if r.Status != "queued" && r.Status != "running" {
			continue
		}
		d.closeOpen(ctx, r, "cancelled", "Cancelled: the homerun daemon restarted. The run was queued again.")
		d.setStatus(r, "cancelled")
		d.mirror(r.Repo).RemoveWorktree(ctx, r.Worktree)
		if _, err := d.Start(ctx, r.Event); err != nil {
			slog.Error("re-queueing run", "run", r.ID, "err", err)
		}
	}
}
```

```go
package daemon

// State is what the TUI shows: the last poll of GitHub, overlaid with local
// runs, which are fresher than the poll.
func (d *Daemon) State() api.State {
	d.mu.Lock()
	defer d.mu.Unlock()
	names := make([]string, 0, len(d.cfg.Repos))
	for n := range d.cfg.Repos {
		names = append(names, n)
	}
	sort.Strings(names)
	// newest first, so the first run to claim a check name wins
	runs := make([]string, 0, len(d.runs))
	for id := range d.runs {
		runs = append(runs, id)
	}
	sort.Sort(sort.Reverse(sort.StringSlice(runs)))

	var st api.State
	for _, name := range names {
		r := api.Repo{Name: name, Unhandled: d.unhandled[name]}
		if v := d.views[name]; v != nil {
			r.Error = v.Error
			for _, it := range v.Items {
				byName := map[string]api.Check{}
				for _, c := range it.Checks {
					byName[c.Name] = c
				}
				overlaid := map[string]bool{}
				for _, id := range runs {
					run := d.runs[id]
					if run.Repo != name || run.Event.SHA != it.SHA {
						continue
					}
					for _, c := range run.Checks {
						if overlaid[c.Name] {
							continue
						}
						overlaid[c.Name] = true
						ac := byName[c.Name]
						ac.Name, ac.Status, ac.Conclusion, ac.RunID = c.Name, c.Status, c.Conclusion, run.ID
						byName[c.Name] = ac
					}
				}
				it.Checks = make([]api.Check, 0, len(byName))
				for _, c := range byName {
					it.Checks = append(it.Checks, c)
				}
				sort.Slice(it.Checks, func(i, j int) bool { return it.Checks[i].Name < it.Checks[j].Name })
				r.Items = append(r.Items, it)
			}
		}
		st.Repos = append(st.Repos, r)
	}
	return st
}

func (d *Daemon) finished(id string) bool {
	d.mu.Lock()
	defer d.mu.Unlock()
	r := d.runs[id]
	return r == nil || r.Status == "done" || r.Status == "cancelled"
}
```

```go
func (d *Daemon) Handler() http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /v1/state", func(w http.ResponseWriter, r *http.Request) { writeJSON(w, d.State()) })
	mux.HandleFunc("POST /v1/reload", func(w http.ResponseWriter, r *http.Request) {
		if err := d.Reload(); err != nil {
			http.Error(w, err.Error(), http.StatusBadRequest)
			return
		}
		w.WriteHeader(http.StatusNoContent)
	})
	mux.HandleFunc("POST /v1/runs", d.handleStart)
	mux.HandleFunc("POST /v1/runs/{id}/cancel", func(w http.ResponseWriter, r *http.Request) {
		if !d.sched.Cancel(r.PathValue("id")) {
			http.Error(w, "run is not queued or running", http.StatusNotFound)
			return
		}
		w.WriteHeader(http.StatusNoContent)
	})
	mux.HandleFunc("GET /v1/runs/{id}/log", d.handleLog)
	return mux
}

func writeJSON(w http.ResponseWriter, v any) {
	w.Header().Set("Content-Type", "application/json")
	json.NewEncoder(w).Encode(v)
}

func (d *Daemon) handleStart(w http.ResponseWriter, r *http.Request) {
	var req api.StartRequest
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
		http.Error(w, err.Error(), http.StatusBadRequest)
		return
	}
	ev, err := d.manualEvent(r.Context(), req)
	if err != nil {
		http.Error(w, err.Error(), http.StatusBadRequest)
		return
	}
	run, err := d.Start(r.Context(), ev)
	if err != nil {
		http.Error(w, err.Error(), http.StatusInternalServerError)
		return
	}
	if run == nil {
		writeJSON(w, api.StartResponse{Message: "nothing to run: no workflow or check matches this event"})
		return
	}
	writeJSON(w, api.StartResponse{RunID: run.ID})
}

// manualEvent builds the event for "run now": a PR by number, or a branch head.
func (d *Daemon) manualEvent(ctx context.Context, req api.StartRequest) (event.Event, error) {
	if _, ok := d.config().Repos[req.Repo]; !ok {
		return event.Event{}, fmt.Errorf("repo %s is not registered (homerun repo add %s)", req.Repo, req.Repo)
	}
	def, err := d.opts.Source.DefaultBranch(ctx, req.Repo)
	if err != nil {
		return event.Event{}, err
	}
	if req.PR != 0 {
		prs, err := d.opts.Source.PullRequests(ctx, req.Repo)
		if err != nil {
			return event.Event{}, err
		}
		for _, p := range prs {
			if p.PR == req.PR {
				return event.ForPR(req.Repo, def, p.PR, p.Title, p.Ref, p.SHA, p.HeadRepo, p.BaseRef, p.BaseSHA), nil
			}
		}
		return event.Event{}, fmt.Errorf("no open PR #%d in %s", req.PR, req.Repo)
	}
	ref := req.Ref
	if ref == "" {
		ref = def
	}
	branches, err := d.opts.Source.Branches(ctx, req.Repo)
	if err != nil {
		return event.Event{}, err
	}
	for _, b := range branches {
		if b.Ref == ref {
			return event.Event{Name: "push", Repo: req.Repo, DefaultBranch: def, SHA: b.SHA, Ref: "refs/heads/" + ref, Before: event.Zero}, nil
		}
	}
	return event.Event{}, fmt.Errorf("no branch %s in %s", ref, req.Repo)
}

func (d *Daemon) handleLog(w http.ResponseWriter, r *http.Request) {
	id := r.PathValue("id")
	if !runID.MatchString(id) {
		http.Error(w, "bad run id", http.StatusBadRequest)
		return
	}
	f, err := os.Open(d.store.LogPath(id))
	if errors.Is(err, os.ErrNotExist) {
		http.Error(w, "no log yet: the run has not started", http.StatusNotFound)
		return
	}
	if err != nil {
		http.Error(w, err.Error(), http.StatusInternalServerError)
		return
	}
	defer f.Close()
	w.Header().Set("Content-Type", "text/plain; charset=utf-8")
	flusher, _ := w.(http.Flusher)
	follow := r.URL.Query().Get("follow") == "1"
	for {
		done := d.finished(id) // checked before copying, so the last copy sees everything
		if _, err := io.Copy(w, f); err != nil {
			return
		}
		if flusher != nil {
			flusher.Flush()
		}
		if !follow || done {
			return
		}
		select {
		case <-r.Context().Done():
			return
		case <-time.After(500 * time.Millisecond):
		}
	}
}

// Serve listens on a unix socket only the current user can open.
func Serve(ctx context.Context, sock string, h http.Handler) error {
	os.Remove(sock)
	l, err := net.Listen("unix", sock)
	if err != nil {
		return err
	}
	if err := os.Chmod(sock, 0o600); err != nil {
		l.Close()
		return err
	}
	srv := &http.Server{Handler: h}
	go func() { <-ctx.Done(); srv.Close() }()
	if err := srv.Serve(l); !errors.Is(err, http.ErrServerClosed) {
		return err
	}
	return nil
}
```

```go
func SetApp(path string, id int64, keyCmd string) error {

		app := &yaml.Node{Kind: yaml.MappingNode, Tag: "!!map", Content: []*yaml.Node{

// edit round-trips the file through yaml.Node so the user's comments survive.
func edit(path string, fn func(root *yaml.Node)) error {
	b, err := os.ReadFile(path)
	if err != nil && !errors.Is(err, fs.ErrNotExist) {
		return err
	}
	var doc yaml.Node
	if len(bytes.TrimSpace(b)) > 0 {
		if err := yaml.Unmarshal(b, &doc); err != nil {
			return fmt.Errorf("%s: %w", path, err)
		}
	}
	if doc.Kind == 0 {
		doc = yaml.Node{Kind: yaml.DocumentNode, Content: []*yaml.Node{{Kind: yaml.MappingNode, Tag: "!!map"}}}
	}
	root := doc.Content[0]
	if root.Kind != yaml.MappingNode {
		return fmt.Errorf("%s: the top level must be a mapping", path)
	}
	fn(root)
	out, err := yaml.Marshal(&doc)
	if err != nil {
		return err
	}
	if err := os.MkdirAll(filepath.Dir(path), 0o700); err != nil {
		return err
	}
	return os.WriteFile(path, out, 0o600)
}

func str(v string) *yaml.Node { return &yaml.Node{Kind: yaml.ScalarNode, Tag: "!!str", Value: v} }

func mapGet(m *yaml.Node, key string) *yaml.Node {
	for i := 0; i+1 < len(m.Content); i += 2 {
		if m.Content[i].Value == key {
			return m.Content[i+1]
		}
	}
	return nil
}

func setKey(m *yaml.Node, key string, v *yaml.Node) {
	for i := 0; i+1 < len(m.Content); i += 2 {
		if m.Content[i].Value == key {
			m.Content[i+1] = v
			return
		}
	}
	m.Content = append(m.Content, str(key), v)
}

func ensureMap(m *yaml.Node, key string) *yaml.Node {
	v := mapGet(m, key)
	if v == nil || v.Kind != yaml.MappingNode {
		v = &yaml.Node{Kind: yaml.MappingNode, Tag: "!!map"}
		setKey(m, key, v)
	}
	return v
}
```

```go
// appName must be unique across GitHub and at most 34 characters.
func appName(host string) string {
	h := strings.Trim(nonName.ReplaceAllString(strings.ToLower(host), "-"), "-")
	if len(h) > 20 {
		h = h[:20]
	}
	return "homerun-" + h + "-" + randHex(2)
}

func randHex(n int) string {
	b := make([]byte, n)
	rand.Read(b)
	return hex.EncodeToString(b)

var page = template.Must(template.New("p").Parse(`<!doctype html><meta charset="utf-8"><title>homerun setup</title>
<form id="f" method="post" action="{{.Action}}"><input type="hidden" name="manifest" value="{{.Manifest}}"></form>
<p>Sending you to GitHub to create the homerun App…</p>
<script>document.getElementById("f").submit()</script>`))

func handler(action, manifestJSON, state string, codes chan<- string) http.Handler {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /{$}", func(w http.ResponseWriter, r *http.Request) {
		page.Execute(w, map[string]any{"Action": template.URL(action), "Manifest": manifestJSON})
	})
	mux.HandleFunc("GET /callback", func(w http.ResponseWriter, r *http.Request) {
		q := r.URL.Query()
		if q.Get("state") != state || q.Get("code") == "" {
			http.Error(w, "unexpected callback: state mismatch or missing code", http.StatusBadRequest)
			return
		}
		select {
		case codes <- q.Get("code"):
		default:
		}
		io.WriteString(w, "GitHub App created. You can close this tab and return to your terminal.")
	})
	return mux
}

// CreateApp runs GitHub's App manifest flow: a local page posts the manifest to
// GitHub, GitHub redirects back with a code, and the code is exchanged for the
// App's id and private key.
func CreateApp(ctx context.Context, org string, public bool, cfgPath string, open func(string) error, out io.Writer) error {
	l, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		return err
	}
	base := "http://" + l.Addr().String()
	state := randHex(16)
	host, _ := os.Hostname()
	m, err := json.Marshal(manifest(appName(host), base+"/callback", public))
	if err != nil {
		return err
	}
	action := "https://github.com/settings/apps/new?state=" + state
	if org != "" {
		action = "https://github.com/organizations/" + url.PathEscape(org) + "/settings/apps/new?state=" + state
	}
	codes := make(chan string, 1)
	srv := &http.Server{Handler: handler(action, string(m), state, codes)}
	go srv.Serve(l)
	defer srv.Close()

	fmt.Fprintf(out, "Opening %s/ to create the GitHub App...\n", base)
	if err := open(base + "/"); err != nil {
		fmt.Fprintf(out, "Could not open a browser. Open this URL yourself: %s/\n", base)
	}
	ctx, cancel := context.WithTimeout(ctx, 10*time.Minute)
	defer cancel()
	var code string
	select {
	case code = <-codes:
	case <-ctx.Done():
		return errors.New("timed out waiting for GitHub to redirect back")
	}
	gc, err := github.NewClient()
	if err != nil {
		return err
	}
	app, _, err := gc.Apps.CompleteAppManifest(ctx, code)
	if err != nil {
		return fmt.Errorf("exchanging the manifest code: %w", err)
	}
	keyPath := filepath.Join(filepath.Dir(cfgPath), "app-key.pem")
	if err := os.MkdirAll(filepath.Dir(keyPath), 0o700); err != nil {
		return err
	}
	if err := os.WriteFile(keyPath, []byte(app.GetPEM()), 0o600); err != nil {
		return err
	}
	if err := config.SetApp(cfgPath, app.GetID(), "cat '"+keyPath+"'"); err != nil {
		return err
	}
	fmt.Fprintf(out, `Created GitHub App %s (id %d).
Its private key is in %s (mode 600). To keep it in a secret manager instead,
store it there, delete the file, and set app.private_key in %s to
{cmd: "<a command that prints the key>"}.

Next:
  1. Install the App on your repos: %s/installations/new
  2. homerun repo add OWNER/NAME
  3. homerun daemon --install
`, app.GetSlug(), app.GetID(), keyPath, cfgPath, app.GetHTMLURL())
	return nil
}
```

```go
// Unit pins PATH because systemd user services start with a minimal PATH that
// usually lacks act and docker.
func Unit(exe, cfgPath, path string) string {
	return fmt.Sprintf(`[Unit]
Description=homerun local CI
After=network-online.target docker.service

[Service]
ExecStart="%s" daemon --config "%s"
Environment=PATH=%s
Restart=on-failure
RestartSec=10

[Install]
WantedBy=default.target
`, exe, cfgPath, path)
}

func InstallSystemd(cfgPath string, out io.Writer) error {
	exe, err := os.Executable()
	if err != nil {
		return err
	}
	dir, err := os.UserConfigDir()
	if err != nil {
		return err
	}
	p := filepath.Join(dir, "systemd", "user", "homerun.service")
	if err := os.MkdirAll(filepath.Dir(p), 0o755); err != nil {
		return err
	}
	if err := os.WriteFile(p, []byte(Unit(exe, cfgPath, os.Getenv("PATH"))), 0o644); err != nil {
		return err
	}
	for _, args := range [][]string{{"--user", "daemon-reload"}, {"--user", "enable", "--now", "homerun.service"}} {
		if b, err := exec.Command("systemctl", args...).CombinedOutput(); err != nil {
			return fmt.Errorf("systemctl %v: %w: %s", args, err, b)
		}
	}
	fmt.Fprintf(out, `Installed and started %s
Logs: journalctl --user -u homerun -f
To keep it running while you are logged out: loginctl enable-linger %s
`, p, os.Getenv("USER"))
	return nil
}
```

```go
import (
	"context"
	"errors"

	"os/exec"

	"github.com/matthew-reed-holden/homerun/internal/config"

)

const minAct = "0.2.89" // the version homerun's act integration was verified against

func Doctor(ctx context.Context, cfgPath string, out io.Writer) error {
	ok := true
	check := func(name string, err error) {
		if err != nil {
			ok = false
			fmt.Fprintf(out, "✗ %s: %v\n", name, err)
			return
		}
		fmt.Fprintf(out, "✓ %s\n", name)
	}
	for _, bin := range []string{"git", "docker", "act"} {
		_, err := exec.LookPath(bin)
		check(bin+" on PATH", err)
	}
	check("docker daemon reachable", exec.CommandContext(ctx, "docker", "info", "--format", "{{.ServerVersion}}").Run())
	check("act >= "+minAct, actVersion(ctx))
	cfg, warns, err := config.LoadUser(cfgPath)
	check("config "+cfgPath, err)
	for _, w := range warns {
		fmt.Fprintf(out, "! %s\n", w)
	}
	if err == nil {
		key, err := cfg.App.PrivateKey.Resolve(ctx)
		check("GitHub App private key readable", err)
		if err == nil {
			c, err := gh.New(cfg.App.ID, []byte(key))
			check("GitHub App key valid", err)
			if err == nil {
				for repo := range cfg.Repos {
					_, err := c.DefaultBranch(ctx, repo)
					check("App installed on "+repo, err)
				}
			}
		}
	}
	if !ok {
		return errors.New("some checks failed")
	}
	return nil
}

func actVersion(ctx context.Context) error {
	b, err := exec.CommandContext(ctx, "act", "--version").Output()
	if err != nil {
		return err
	}
	f := strings.Fields(string(b)) // "act version 0.2.89"
	if len(f) == 0 || !versionAtLeast(f[len(f)-1], minAct) {
		return fmt.Errorf("found %q", strings.TrimSpace(string(b)))
	}
	return nil
}

func versionAtLeast(v, min string) bool {
	a, b := strings.Split(v, "."), strings.Split(min, ".")
	for i := range b {
		if i >= len(a) {
			return false
		}
		x, err1 := strconv.Atoi(a[i])
		y, err2 := strconv.Atoi(b[i])
		if err1 != nil || err2 != nil {
			return false
		}
		if x != y {
			return x > y
		}
	}
	return true
}
```

```go
func loadClient(ctx context.Context, path string) (*config.User, *gh.Client, error) {

func cmdDaemon(args []string) error {
	fs, cfgPath := flags("daemon")
	install := fs.Bool("install", false, "install and start a systemd user service")
	fs.Parse(args)
	if *install {
		return setup.InstallSystemd(*cfgPath, os.Stdout)
	}
	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()
	cfg, client, err := loadClient(ctx, *cfgPath)
	if err != nil {
		return err
	}
	act, err := exec.LookPath("act")
	if err != nil {
		return errors.New("act not found on PATH (see: homerun doctor)")

		return err

			stop()
```

```go
package tui

import (
	"bufio"
	"context"
	"fmt"
	"os/exec"
	"strings"
	"time"

	tea "github.com/charmbracelet/bubbletea"
	"github.com/charmbracelet/lipgloss"
	"github.com/matthew-reed-holden/homerun/internal/api"
)

type Row struct {
	Text  string
	Item  *api.Item
	Check *api.Check
}

func Icon(status, conclusion string) string {
	switch {
	case status != "completed":
		return "⟳"
	case conclusion == "success":
		return "✔"
	case conclusion == "failure", conclusion == "timed_out", conclusion == "action_required":
		return "✘"
	default:
		return "○"
	}
}

func Rollup(cs []api.Check) string {
	if len(cs) == 0 {
		return "·"
	}
	out := "✔"
	for _, c := range cs {
		switch Icon(c.Status, c.Conclusion) {
		case "✘":
			return "✘"
		case "⟳":
			out = "⟳"
		}
	}
	return out
}

func Rows(r api.Repo) []Row {
	var rows []Row
	for i := range r.Items {
		it := &r.Items[i]
		rows = append(rows, Row{Text: fmt.Sprintf("%s %s  %s", Rollup(it.Checks), it.Label, short(it.SHA)), Item: it})
		for j := range it.Checks {
			c := &it.Checks[j]
			rows = append(rows, Row{Text: "    " + Icon(c.Status, c.Conclusion) + " " + c.Name, Item: it, Check: c})
		}
	}
	if len(r.Unhandled) > 0 {
		rows = append(rows, Row{Text: "not handled locally: " + strings.Join(r.Unhandled, ", ")})
	}
	return rows
}

func short(sha string) string {
	if len(sha) > 7 {
		return sha[:7]
	}
	return sha
}

// window returns the slice [start, end) of n rows that keeps sel visible in height rows.
func window(n, sel, height int) (int, int) {
	if n <= height {
		return 0, n
	}
	start := sel - height/2
	start = max(0, min(start, n-height))
	return start, start + height
}

var (
	green  = lipgloss.NewStyle().Foreground(lipgloss.Color("2"))
	red    = lipgloss.NewStyle().Foreground(lipgloss.Color("1"))
	yellow = lipgloss.NewStyle().Foreground(lipgloss.Color("3"))
	dim    = lipgloss.NewStyle().Foreground(lipgloss.Color("8"))
	sel    = lipgloss.NewStyle().Reverse(true)
	box    = lipgloss.NewStyle().Border(lipgloss.RoundedBorder())
)

// colour paints the status icons in a line.
func colour(s string) string {
	r := strings.NewReplacer("✔", green.Render("✔"), "✘", red.Render("✘"), "⟳", yellow.Render("⟳"), "○", dim.Render("○"))
	return r.Replace(s)
}

type (
	stateMsg  struct{ s *api.State }
	errMsg    struct{ err error }
	tickMsg   struct{}
	statusMsg string
	logMsg    struct{ run, line string }
	logEndMsg struct{ run string }
)

type model struct {
	c         *api.Client
	state     api.State
	err       error
	repo      int
	row       int
	focus     int // 0: repos, 1: rows
	logRun    string
	logName   string
	log       []string
	lines     chan string
	stopLog   context.CancelFunc
	status    string
	w, h      int
}

func Run(c *api.Client) error {
	m := &model{c: c, w: 100, h: 30}
	_, err := tea.NewProgram(m, tea.WithAltScreen()).Run()
	if m.stopLog != nil {
		m.stopLog()
	}
	return err
}

func (m *model) Init() tea.Cmd { return tea.Batch(m.fetch(), tick()) }

func tick() tea.Cmd { return tea.Tick(2*time.Second, func(time.Time) tea.Msg { return tickMsg{} }) }

func (m *model) fetch() tea.Cmd {
	return func() tea.Msg {
		s, err := m.c.State(context.Background())
		if err != nil {
			return errMsg{err}
		}
		return stateMsg{s}
	}
}

func (m *model) rows() []Row {
	if m.repo >= len(m.state.Repos) {
		return nil
	}
	return Rows(m.state.Repos[m.repo])
}

func (m *model) selected() *Row {
	rows := m.rows()
	if m.focus != 1 || m.row >= len(rows) {
		return nil
	}
	return &rows[m.row]
}

func (m *model) Update(msg tea.Msg) (tea.Model, tea.Cmd) {
	switch msg := msg.(type) {
	case tea.WindowSizeMsg:
		m.w, m.h = msg.Width, msg.Height
	case stateMsg:
		m.state, m.err = *msg.s, nil
		m.repo = min(m.repo, max(0, len(m.state.Repos)-1))
		m.row = min(m.row, max(0, len(m.rows())-1))
	case errMsg:
		m.err = msg.err
	case tickMsg:
		return m, tea.Batch(m.fetch(), tick())
	case statusMsg:
		m.status = string(msg)
	case logMsg:
		if msg.run == m.logRun {
			if m.log = append(m.log, msg.line); len(m.log) > 2000 {
				m.log = m.log[len(m.log)-2000:]
			}
			return m, m.nextLine()
		}
	case logEndMsg:
		if msg.run == m.logRun {
			m.log = append(m.log, dim.Render("— end of log —"))
		}
	case tea.KeyMsg:
		return m, m.key(msg.String())
	}
	return m, nil
}

func (m *model) key(k string) tea.Cmd {
	switch k {
	case "q", "ctrl+c":
		m.closeLog()
		return tea.Quit
	case "tab", "left", "right", "h", "l":
		m.focus = 1 - m.focus
	case "j", "down":
		m.move(1)
	case "k", "up":
		m.move(-1)
	case "esc":
		m.closeLog()
	case "enter":
		if r := m.selected(); r != nil && r.Check != nil && r.Check.RunID != "" {
			return m.follow(r.Check)
		}
		m.status = "no local log for this row (select a check homerun ran)"
	case "r":
		if r := m.selected(); r != nil && r.Item != nil {
			req := api.StartRequest{Repo: m.state.Repos[m.repo].Name, PR: r.Item.PR}
			if r.Item.PR == 0 {
				req.Ref = r.Item.Ref
			}
			return func() tea.Msg {
				resp, err := m.c.Start(context.Background(), req)
				if err != nil {
					return statusMsg("rerun failed: " + err.Error())
				}
				if resp.RunID == "" {
					return statusMsg(resp.Message)
				}
				return statusMsg("queued run " + resp.RunID)
			}
		}
	case "c":
		if r := m.selected(); r != nil && r.Check != nil && r.Check.RunID != "" {
			id := r.Check.RunID
			return func() tea.Msg {
				if err := m.c.Cancel(context.Background(), id); err != nil {
					return statusMsg("cancel: " + err.Error())
				}
				return statusMsg("cancelled run " + id)
			}
		}
	case "o":
		if r := m.selected(); r != nil {
			url := r.Item.URL
			if r.Check != nil && r.Check.URL != "" {
				url = r.Check.URL
			}
			if url != "" {
				exec.Command("xdg-open", url).Start()
			}
		}
	}
	return nil
}

func (m *model) move(d int) {
	if m.focus == 0 {
		m.repo = max(0, min(m.repo+d, len(m.state.Repos)-1))
		m.row = 0
		return
	}
	m.row = max(0, min(m.row+d, len(m.rows())-1))
}

func (m *model) closeLog() {
	if m.stopLog != nil {
		m.stopLog()
	}
	m.stopLog, m.logRun, m.log = nil, "", nil
}

func (m *model) follow(c *api.Check) tea.Cmd {
	m.closeLog()
	ctx, cancel := context.WithCancel(context.Background())
	m.stopLog, m.logRun, m.logName = cancel, c.RunID, c.Name
	lines := make(chan string, 256)
	m.lines = lines
	go func() {
		defer close(lines)
		body, err := m.c.Log(ctx, c.RunID, true)
		if err != nil {
			lines <- "error: " + err.Error()
			return
		}
		defer body.Close()
		sc := bufio.NewScanner(body)
		sc.Buffer(make([]byte, 64*1024), 1024*1024)
		for sc.Scan() {
			select {
			case lines <- sc.Text():
			case <-ctx.Done():
				return
			}
		}
	}()
	return m.nextLine()
}

func (m *model) nextLine() tea.Cmd {
	ch, run := m.lines, m.logRun
	return func() tea.Msg {
		l, ok := <-ch
		if !ok {
			return logEndMsg{run}
		}
		return logMsg{run, l}
	}
}

func (m *model) View() string {
	if m.err != nil && len(m.state.Repos) == 0 {
		return "homerun: " + m.err.Error() + "\n\nStart the daemon with: homerun daemon   (q to quit)\n"
	}
	topH := m.h - 3
	if m.logRun != "" {
		topH = m.h / 2
	}
	inner := max(1, topH-2)

	var left []string
	for i, r := range m.state.Repos {
		var all []api.Check
		for _, it := range r.Items {
			all = append(all, it.Checks...)
		}
		line := Rollup(all) + " " + r.Name
		if r.Error != "" {
			line = "✘ " + r.Name + " (error)"
		}
		if i == m.repo && m.focus == 0 {
			line = sel.Render(line)
		}
		left = append(left, colour(line))
	}
	leftW := 30
	rightW := max(20, m.w-leftW-4)

	rows := m.rows()
	var right []string
	if m.repo < len(m.state.Repos) && m.state.Repos[m.repo].Error != "" {
		right = append(right, red.Render(m.state.Repos[m.repo].Error))
	}
	start, end := window(len(rows), m.row, inner-len(right))
	for i := start; i < end; i++ {
		line := rows[i].Text
		if len(line) > rightW {
			line = line[:rightW-1] + "…"
		}
		if i == m.row && m.focus == 1 {
			line = sel.Render(line)
		}
		right = append(right, colour(line))
	}
	top := lipgloss.JoinHorizontal(lipgloss.Top,
		box.Width(leftW).Height(inner).Render(strings.Join(left, "\n")),
		box.Width(rightW).Height(inner).Render(strings.Join(right, "\n")))

	var b strings.Builder
	b.WriteString(top + "\n")
	if m.logRun != "" {
		logH := max(1, m.h-topH-4)
		ls := m.log
		if len(ls) > logH {
			ls = ls[len(ls)-logH:]
		}
		b.WriteString(dim.Render(m.logName+"  (esc to close)") + "\n" + strings.Join(ls, "\n") + "\n")
	}
	help := "tab switch pane · j/k move · enter log · r rerun · c cancel · o open · q quit"
	if m.status != "" {
		help += "   " + m.status
	}
	b.WriteString(dim.Render(help))
	return b.String()
}
```
