homerun TUI reference

The target design for homerun's terminal UI: a gh-dash style dashboard of PR searches for the picked repo, with a tabbed preview you can move into the way you move between lazygit's panels. Each screen is drawn the way homerun will render it at about 120×36 unless marked otherwise.

Principles

Search first

Every PR tab is a saved GitHub search, scoped to the picked repo. / edits the current tab's query in GitHub's own syntax, so nothing new has to be learned.

Move in, not just look

The preview is a panel you can enter. l or enter goes in, h or esc comes out, one level at a time. A breadcrumb in the title always says where you are.

Width goes to the work

Lists stay narrow. A diff, a log or a check tree takes the whole screen and the PR list steps aside until esc.

Local and GitHub, side by side

homerun's own checks and GitHub-hosted ones share one column and one tree. A PR homerun has not run on says so instead of looking broken.

Frames

  • Rounded boxes with the title set into the top border, as today.
  • The focused box has a bright border and a bold title; the rest are dim.
  • Tabs sit on the first line inside a box: the active tab is a filled blue chip, the others dim text.
  • Counts ride on tab labels: Checks 2/5, Files 1/4.
  • Drill-down titles are breadcrumbs: #41 › CI / e2e › Run tests.
  • Dialogs are yellow-bordered and centred over a dimmed screen.

Motion and the ballpark

Baseball lives in motion and empty states only; statuses keep plain words (queued, running, failed). Every animation lasts about a second, never blocks a key, and plays once, except the loading runner. animations: on | reduced | off in config; reduced keeps the runner and banners and drops movement.

Loading: running the bases

frames ◆◇◇◇ → ◇◆◇◇ → ◇◇◆◇ → ◇◇◇◆ “searching GitHub…”

Replaces every spinner: searches, detail fetches, Doctor's checks.

Merge: home run

Plays over the preview pane when a merge succeeds, about 1.6 seconds at 70ms a frame; any key skips it. The pitch comes in from the mound, the swing flashes on contact, the ball follows a projectile path (harmonica) over the fence trailing dots, the bleachers stand, then the block-letter banner names the PR. The row leaves the tab on the next refresh.

  • The table's title shows the tab's full query, so / starts from something you can read.
  • The first column is homerun's own rollup; CI counts every check, homerun's and GitHub's.

  • Branches, Runs and the header's run count cover the picked repo only.
